# Codenotch 1.22.0

This release makes accounts first-class: add more than one account for each supported provider and keep every enabled account visible at the same time.

## What's new

- Separate managed accounts for supported browser-login, CLI-login, web-session and API-key providers.
- Duplicate-email protection within a provider, while allowing the same email across different providers.
- A compact two-column Add Account picker grouped by **Sign in with browser**, **API key**, and **Unavailable**.
- Independent provider tabs for managing, re-authenticating and removing accounts and their saved data.
- Menu-bar-only operation so closing or hiding the Dock presence does not stop the notch.
- Compact tooltip provider codes such as **AG** and **CX**.
- Monthly subscription end dates beneath tooltip titles when the provider reports a monthly reset.

## Downloads

- `Codenotch.dmg` — universal macOS build for Apple silicon and Intel Macs.
- `Codenotch-Setup.exe` — Windows installer, built by the Windows release workflow.

The macOS build is locally signed but not Apple-notarized. If macOS reports that the app is damaged after installation, run:

```sh
xattr -dr com.apple.quarantine /Applications/Codenotch.app
```

The Windows installer is not code-signed, so Windows SmartScreen may require **More info → Run anyway** on first launch.
